# 4. API DOKÜMANTASYONU VE DEĞİŞİKLİK BİLDİRİMLERİ

- **Dokümantasyon Konumu:** Projenin ana dizininde dokümantasyon dosyaları tutulur (Örn: `ControllerName-Endpoints.md`).
- **Endpoint Değişiklikleri:** Mevcut bir endpoint'in adını (route), aldığı request/response modelini (DTO) veya HTTP metodunu değiştirirsen; bunu bana mutlaka bildir ve dokümantasyon dosyasını anında güncelle.
- **Yeni Endpoint:** Yeni bir Controller veya endpoint yazdığında, API dokümantasyonunu (HTTP metodu, route, yetki, payload) mutlaka oluştur.
